# HomeTiles v0.6.5

v0.6.5 adds Home Assistant Cover controls and improves display, storage and
interaction stability across the supported and community-test devices.

## Upgrade Order

1. Update **HomeTiles Bridge to v0.6.35** through HACS and restart Home Assistant.
2. Update the display to HomeTiles v0.6.5.

## Highlights

- New localized **Cover** tiles and a Light-popup-based Cover popup with
  feature-aware position, tilt, open, close and stop controls.
- Improved Guition ESP32-S3 touch, RGB display synchronization, OTA,
  screenshots, slideshow memory use and rate-limited diagnostics.
- Unified normal and screensaver brightness across device UI, MQTT and Home
  Assistant without losing the safe device-specific PWM ranges.
- Expanded the Waveshare 8-inch folder cache to six grids and reclaimed
  internal RAM without changing the other device profiles.
- Added a live downloadable SD diagnostic report without persistent diagnostic
  history.
- Added a separate community-test image for Guition JC8012P4A1 V2
  (`SKU:10153002-V2`).
- Corrected JC1060 SD startup by applying the board's active-low GPIO45 power
  reset before mounting the card.

The Guition ESP32-4848S040 ESP32-S3 image remains **experimental** and does not
support Camera tiles.

Hardware-confirmed targets remain M5Stack Tab5, Waveshare 4B/86 Panel/8-inch
and Guition JC8012 V1. Waveshare 7/10.1-inch, Guition JC8012 V2, Guition
JC1060 and Guition ESP32-S3 remain community-test images.

Use the regular `.bin` for OTA and `_factory.bin` only for the first USB flash
or a complete reset.
