# HomeTiles v0.6.6

v0.6.6 improves Home Assistant controls, firmware updates, ESP32-S3 display
recovery, Weather interaction, and the installation documentation.

## Upgrade Order

1. Update **HomeTiles Bridge to v0.6.36** through HACS and restart Home
   Assistant.
2. Update the display to HomeTiles v0.6.6.

## Highlights

- Aligns Climate controls with current Home Assistant capabilities, including
  availability, target-humidity steps, horizontal swing modes, and validated
  target ranges.
- Disables Light tile and popup controls consistently while an entity is
  unavailable, including the Web Admin preview.
- Opens the Weather popup after either a short or long press is released while
  still ignoring scrolling and cancelled presses.
- Adds an ESP32-S3 RGB scanout resynchronization after boot and after a real
  update check, scoped only to `DEVICE_GUITION_ESP32_4848S040`.
- Stages local Web Admin OTA images completely in PSRAM on every supported
  ESP32-P4 profile before any flash write and reduces browser upload overhead.
- Adds a guided USB browser installer with separate safe **Update** and
  **First install / factory reset** paths, exact device validation, visible
  progress, and a bounded copyable flash log.
- Adds step-by-step manual flashing and update instructions plus practical
  screensaver JPEG size, color, and resolution guidance.

## Hardware Status

The established hardware-confirmed profiles remain M5Stack Tab5, Waveshare
4B/86 Panel/8-inch, Guition JC8012 V1, and Guition ESP32-4848S040 ESP32-S3.

Waveshare 7/10.1-inch and Guition JC8012 V2 still need complete physical-device
validation. JC1060 SD-card operation still needs confirmation on the exact
`_I_W_Y` hardware.

The new Weather long-release gesture, S3 boot/update-check scanout recovery,
and Web Admin OTA transport changes have focused regression coverage and build
coverage but still require final testing on the affected physical devices.

Use the regular `.bin` for OTA or the browser installer's **Update** mode. Use
`_factory.bin` only for the first installation or an intentional full reset.
